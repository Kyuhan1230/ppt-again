# 지원되는 입력

HTML 전체가 항상 한 장의 장표인 것은 아닙니다. 메뉴, 버튼, 설명문이 함께 있는 경우가 있어 다음 기준으로 장표 영역을 찾습니다.

- 크기가 정해진 `[data-slide]` 요소를 사용합니다. 다른 요소는 화면에서 장표 선택자를 지정할 수 있습니다.
- 명시적인 장표 영역이 없으면 큰 바깥 SVG의 `viewBox`를 사용합니다. 작은 아이콘은 장표로 취급하지 않습니다.
- 기존 장표 JSON을 포함한 정적 HTML도 일부 지원합니다. 모든 HTML 편집기 형식과 호환되는 것은 아닙니다.

자동 검사는 16:9·4:3·세로형의 가상 입력을 코드에서 만듭니다. 서로 다른 비율을 한 PPT에 섞는 기능은 지원하지 않습니다. 실제 문서와 입력용 예제 파일은 저장소에 보관하지 않습니다.

HTML은 16MB 이하, 함께 선택할 자산은 합계 64MB 이하로 준비하세요. 외부 URL의 이미지·글꼴은 자동으로 내려받지 않습니다. 사용할 파일을 상대 경로에 맞게 함께 선택해 주세요.

## 글꼴과 편집 범위

브라우저와 PowerPoint가 같은 글꼴을 사용할 수 있어야 결과를 비교할 수 있습니다. 운영체제와 설치된 글꼴에 따라 굵기와 줄바꿈이 달라질 수 있습니다. 변환이 끝나도 화면이 완전히 같다는 뜻은 아닙니다.

글자, 기본 사각형·원·타원·선은 지원 범위 안에서 각각 편집할 수 있습니다. PNG·JPEG는 그림입니다. 복잡한 SVG 경로·장식은 그림으로 남을 수 있습니다. 그 안의 모든 요소를 PowerPoint 도형으로 바꾸지는 않습니다.

입력 스크립트, iframe 앱, canvas의 의미 복원, 복잡한 3D 효과·애니메이션, 표·차트 데이터 편집은 지원 범위에 포함하지 않습니다. 실패나 지원 제한이 표시되면 입력을 단순하게 바꾼 뒤 다시 확인해 주세요.

## PPT → HTML 모듈

개발자용 `readPptx`와 `exportHtml`은 명시적인 위치·RGB 색·글꼴을 가진 기본 글자, 사각형·타원, 선, 그림, 배율 1의 평면 그룹을 처리합니다. 원래 PPT의 물리 크기를 기록하고, 재입력 때 현재 HTML 문구와 좌표를 읽습니다. 브라우저 창의 크기를 PPT 좌표로 저장하지 않습니다.

테마 배경·상속된 서식·표·차트·SmartArt·중첩 또는 확대된 그룹·복잡한 효과·애니메이션은 아직 지원하지 않습니다. 해석하지 못한 항목은 실패로 알립니다. 원본의 모든 서식·메모·메타데이터를 보존하는 무손실 변환을 보장하지 않습니다.

PPTX 입력은 64MiB, 압축 해제된 개별 항목은 16MiB, 전체는 128MiB까지 처리합니다. 출력 HTML은 재입력 한도인 16MiB 이내여야 합니다. 외부 참조, 매크로, 내장 문서는 받지 않습니다. 글꼴 파일을 자동으로 PPT에 넣지는 않으므로 사용할 PC에 같은 글꼴이 필요합니다.
