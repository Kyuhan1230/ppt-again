# 지원되는 입력

HTML 전체가 항상 한 장의 장표인 것은 아닙니다. 메뉴, 버튼, 설명문이 함께 있는 경우가 있어 다음 기준으로 장표 영역을 찾습니다.

- 크기가 정해진 `[data-slide]` 요소를 사용합니다. 다른 요소는 화면에서 장표 선택자를 지정할 수 있습니다.
- 명시적인 장표 영역이 없으면 큰 바깥 SVG의 `viewBox`를 사용합니다. 작은 아이콘은 장표로 취급하지 않습니다.
- 기존 장표 JSON을 포함한 정적 HTML도 일부 지원합니다. 모든 HTML 편집기 형식과 호환되는 것은 아닙니다.

자동 검사는 16:9·4:3·세로형의 가상 입력을 코드에서 만듭니다. 서로 다른 비율을 한 PPT에 섞는 기능은 지원하지 않습니다. 실제 문서와 입력용 예제 파일은 저장소에 보관하지 않습니다.

CLI에서도 같은 지원 범위를 사용합니다. `--assets`로 지정한 폴더의 상대 경로 자산을 읽으며, 자산 폴더 안의 심볼릭 링크는 허용하지 않으며 파일과 하위 폴더를 합쳐 최대 1,024개 항목을 읽습니다. 사용 방법은 [README](../README.md#명령어로-변환하기)를 참고하세요.

HTML은 16MiB 이하, 함께 선택할 자산은 합계 64MiB 이하로 준비하세요. 외부 URL의 이미지·글꼴은 자동으로 내려받지 않습니다. 사용할 파일을 상대 경로에 맞게 함께 선택해 주세요.

## 글꼴과 편집 범위

일반 HTML에서 원래 글꼴을 사용할 수 없으면 일부 경우 Pretendard 일반체 또는 굵은체로 대체하여 PPT에 포함하고 안내합니다. SVG 글자, 기울임과 누락된 외부 글꼴 등은 대체하지 못할 수 있습니다. [글꼴 라이선스](../assets/fonts/pretendard/OFL.txt)를 참고하세요. 브라우저와 PowerPoint가 같은 글꼴을 사용할 수 있어야 결과를 비교할 수 있습니다. 운영체제와 설치된 글꼴에 따라 굵기와 줄바꿈이 달라질 수 있습니다. 변환이 끝나도 화면이 완전히 같다는 뜻은 아닙니다.

글자, 기본 사각형·원·타원·선은 지원 범위 안에서 각각 편집할 수 있습니다. PNG·JPEG는 그림입니다. 복잡한 SVG 경로·장식은 그림으로 남을 수 있습니다. 그 안의 모든 요소를 PowerPoint 도형으로 바꾸지는 않습니다.

크기가 정해진 일반 HTML 표와 행·열 병합 표는 PowerPoint 표로 생성합니다. 셀 문구·수치와 명시적인 서식, 불균일한 열 너비를 지원합니다. 일부 복잡한 표는 배경 그림과 편집 가능한 글자 상자로 분리됩니다. 이 경우 PPT 표 셀로 편집하거나 배경과 글자를 함께 이동할 수 없습니다. 중첩 표, 셀 내부 그림·변환 효과, 해석할 수 없는 격자·서식은 실패로 알립니다.

브라우저가 소수 픽셀의 셀 테두리를 반올림할 수 있습니다. PPT에서 가져온 일부 얇은 테두리는 원래 두께를 별도로 기록해 왕복 시 복원합니다. 그 밖의 테두리는 두께가 달라질 수 있습니다.

항목·계열·수치를 JSON으로 명시한 세로 막대·꺾은선·원형 차트는 PowerPoint 차트로 만듭니다. 그림이나 임의의 SVG에서 수치를 추정하지 않습니다. 생성한 HTML에서는 차트 JSON의 수치를 수정해 다시 출력할 수 있습니다. SVG 그림을 직접 고친 경우에는 데이터와의 불일치를 알립니다. 원형은 한 계열만 지원하며, 혼합·3D 차트와 개별 항목의 복잡한 서식은 지원하지 않습니다.

입력 스크립트, iframe 앱, canvas의 의미 복원, 복잡한 3D 효과·애니메이션은 지원 범위에 포함하지 않습니다. 실패나 지원 제한이 표시되면 입력을 단순하게 바꾼 뒤 다시 확인해 주세요.

일부 장표에만 오류가 있으면 가능한 장표만 따로 다운로드할 수 있으며 제외된 장표를 안내합니다. 장표에 연결되지 않은 오류는 부분 다운로드로 무시할 수 없습니다.

## PPT → HTML

`readPptx`와 `exportHtml`은 명시적인 위치·RGB 색·글꼴을 가진 기본 글자, 사각형·타원, 선, 그림, 배율 1의 평면 그룹을 처리합니다. 원래 PPT의 물리 크기를 기록하고, 재입력 때 현재 HTML 문구와 좌표를 읽습니다. 브라우저 창의 크기를 PPT 좌표로 저장하지 않습니다.

명시적인 단색 테마 배경은 연결된 테마와 색상 매핑을 따라 HTML의 단색 배경으로 바꿉니다. 사각형으로 잘라낸 PNG·JPEG 그림은 잘린 영역을 유지하며, 다시 PPT로 변환할 때도 원본 그림과 자르기 범위를 사용합니다. 타원형 사진도 모양을 유지합니다. 타원에 가까운 일부 자유형 사진 마스크는 타원으로 근사하며, 그림자는 다시 PPT로 저장할 때 빠질 수 있습니다. HTML의 자르기 표시는 `object-view-box`를 지원하는 최신 브라우저가 필요합니다. 음수 자르기나 복잡한 그림 채우기는 지원하지 않습니다.

읽을 수 있는 문단의 줄 간격, 앞뒤 간격, 들여쓰기와 정렬은 HTML에 반영합니다. 자동 번호와 글머리표, 탭은 일부 배치를 근사하며, 문단별 간격을 HTML에서 다시 PPT로 저장할 때는 차이가 생길 수 있습니다. 위·아래 첨자와 단색 형광펜은 지원 범위에서 유지합니다. 원본 글꼴 이름은 HTML에 기록하고, 설치된 굵은 글꼴의 전체 이름을 브라우저가 찾을 수 있도록 처리합니다. 글꼴 파일은 PPT에서 추출해 HTML에 넣지 않으므로 해당 글꼴이 없는 컴퓨터에서는 대체 글꼴과 다른 줄바꿈이 나타날 수 있습니다.

글자 커닝이 꺼진 상태는 표시와 재출력에 반영합니다. 글자 크기에 따라 커닝을 켜는 원본 기준값 자체는 다시 만든 PPT에 유지하지 않으므로, 이후 글자 크기를 바꾸면 간격이 달라질 수 있습니다.

일반·병합 표의 현재 셀 값과 명시적인 행·열 크기·서식을 읽습니다. 실제 PowerPoint에서 수정한 표를 다시 HTML로 출력하고, 현재 HTML 셀 값을 PPT로 돌려보낼 수 있습니다.

지원하는 세 종류의 차트는 내부 워크시트의 현재 수치와 차트 데이터를 함께 확인합니다. 값이 서로 다르거나 셀이 비어 있으면 실패로 알립니다. 수식 계산, 외부 워크북, 숨긴 행·열, 필터, 복잡한 레이블·개별 서식은 지원하지 않습니다.

복잡한 테마 배경·SmartArt·복잡한 효과·애니메이션은 모두 재현하지 못합니다. 부분 가져오기에서는 일부 마스터 객체와 확대된 그룹, 도형·그림 효과를 근사해 보존하며, 일부 수식은 원본에 들어 있는 그림으로 표시합니다. 그림으로 표시한 수식은 수식으로 편집할 수 없습니다. 수식 대체 표의 테두리는 그림에 포함된 부분만 보이며, 별도 선으로는 가져오지 않습니다. 일부 직선 화살표의 끝은 HTML에서 SVG로 표시하고, 다시 만든 PPT에서는 선과 그림으로 분리합니다. 해석하지 못한 시각 객체는 경고 표시 상자로 남기고, 손상된 구조·외부 참조·리소스 제한 오류는 계속 실패로 처리합니다. 원본의 모든 서식·메모·메타데이터를 보존하는 무손실 변환을 보장하지 않습니다.

PPTX 입력은 64MiB, 압축 해제된 개별 항목은 16MiB, 전체는 128MiB까지 처리합니다. 수식 대체 PNG는 3,200만 픽셀과 압축 해제된 이미지 데이터 128MiB 이하여야 합니다. 차트의 내부 워크북도 같은 전체 예산에 포함합니다. 출력 HTML은 재입력 한도인 16MiB 이내여야 합니다. 외부 참조, 매크로, 사용하지 않는 내장 문서는 받지 않습니다. HTML에서 사용한 글꼴 파일을 함께 제공하면 지원되는 정적 TTF·WOFF2는 PPT에 포함할 수 있습니다. 가변 글꼴 등 지원하지 않는 형식과 포함되지 않은 글꼴에는 제한이 있습니다. PPT에 든 글꼴 파일을 HTML에 자동 배포하지 않습니다.


### PPTX 가져오기 글꼴 선택과 미리보기

HTML 글꼴은 원본 유지, 맑은 고딕(`Malgun Gothic`), `Pretendard` 중 선택합니다. 대체를 선택하면 본문·서식 구간·표 등 지원되는 텍스트의 글꼴 이름을 바꾸고 원본 내장 글꼴은 재배포하지 않습니다. 선택한 글꼴이 해당 PC에 없으면 브라우저에서 다른 글꼴로 보일 수 있으므로 설치 여부와 줄바꿈을 확인하세요. 글꼴 변경만으로 지원하지 않는 도형·그라데이션·아이콘이 지원되는 것은 아닙니다.

PPTX→HTML은 안전한 파싱과 HTML 생성을 완료했다면 미리보기를 실행하지 못해도 경고와 함께 내려받을 수 있습니다. HTML→PPTX는 실제 렌더링·글꼴·배치 측정이 계속 필수입니다. 원본 파일은 덮어쓰지 않습니다.
