# 라이선스 안내

프로젝트 코드는 [MIT 라이선스](LICENSE)로 제공합니다. 패키지는 실수로 npm에 게시되지 않도록 `private: true`로 설정했습니다.

의존 패키지는 각 저작권자의 라이선스를 따릅니다. 고정 버전은 `package-lock.json`에 기록하며, 설치된 각 패키지의 LICENSE 파일에서 조건을 확인할 수 있습니다. 이 저장소는 해당 라이브러리나 상용 글꼴의 권리를 주장하지 않습니다.

예제에는 회사·고객 자료와 외부 이미지·글꼴 파일을 포함하지 않았습니다. 예제의 문구와 일정은 기능 확인을 위해 작성한 가상 내용입니다.

Microsoft, PowerPoint, Edge는 각 권리자의 제품명입니다. 이 프로젝트와의 제휴나 보증을 뜻하지 않습니다.

## dom-to-pptx

HTML 직접 텍스트의 화면 범위를 측정하는 코드는 [dom-to-pptx](https://github.com/atharva9167j/dom-to-pptx/tree/e1805f5d1314388212eea8d92bb077c511385a39)의 텍스트 노드 처리 방식을 수정해 사용합니다. 원본과 달리 여러 줄 및 지원하지 않는 공백은 거부하고, 자동 크기 조정을 사용하지 않습니다.
