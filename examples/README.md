# 가상 장표 예제

예제의 문구와 일정은 이 저장소를 위해 새로 작성했습니다. 실제 회사 자료가 아닙니다. 외부 이미지·폰트 파일을 포함하지 않습니다.

| 파일 | 형식 | 확인할 일 |
| --- | --- | --- |
| weekly-review.html | 16:9 정적 HTML, 2장 | 제목·숫자 수정, 여러 장 출력 |
| delivery-timeline.html | 4:3 SVG, 1장 | 선택자 없이 장표 탐색, 글자·선·도형 |
| handoff-note.html | 세로형 HTML, 1장 | 세로 비율, 전달 사항 수정 |

`npm start`로 화면을 연 뒤 파일을 선택하세요. 파일을 받은 사람이 PowerPoint에서 문구를 바꾸고 저장할 수 있는지 확인해 보세요.
